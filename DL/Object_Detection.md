Задача компьютерного зрения: найти на изображении объекты нужных классов и определить их положение.
- **Classification**: отвечает только _что есть на изображении_  
- **Detection**: отвечает _что и где находится_  
- **Segmentation**: отвечает _какие именно пиксели принадлежат объекту_  

>**Bounding box** - прямоугольник вокруг объекта
>**Confidence** - уверенность модели в предсказании. Например, `0.92` означает, что модель с высокой вероятностью считает найденный объект правильным.
>**IoU** = площадь пересечения / площадь объединения

### Метрики и post-processing в детекции
В детекции предсказание считается верным, если IoU выше порога
- **Precision** = TP / (TP + FP)
- **Recall** = TP / (TP + FN)
- **AP** - площадь под precision-recall кривой для одного класса.  
Модель сортирует предсказания по confidence, затем постепенно меняет порог и строит PR-кривую.
- **mAP** - средний AP по всем классам.
- **Non-Maximum Suppression** - убирает дублирующиеся bounding boxes вокруг одного объекта.

## Two-stage object detection

1. Найти возможные области с объектами  
2. Уточнить, что это за объект и где он находится 

#### R-CNN
Это ранний метод обнаружения объектов (2014), который сначала предлагает регионы-кандидаты на изображении (~2000), затем извлекает из каждого признаки с помощью CNN и классифицирует их, но работает сравнительно медленно из-за отдельной обработки каждого региона. [Подробнее](https://habr.com/ru/companies/jetinfosystems/articles/498294/)
![](../attachments/Pasted%20image%2020260604141342.png)
Важно, что вместо того чтобы проверять все возможные прямоугольники на изображении, R-CNN сначала использует Selective Search:

>Selective Search сначала разбивает изображение на маленькие похожие сегменты по цвету, текстуре и форме. Затем он постепенно объединяет соседние похожие сегменты в более крупные области и выдаёт bounding boxes вокруг них как возможные области с объектами.

#### Fast R-CNN
Довольно быстро теми же авторами было предложено улучшение в виде Fast R-CNN сети
1. Извлечение карты признаков изображения (не для каждой гипотезы по отдельности, а для всего изображения целиком);
2. Поиск гипотез (аналогично R-CNN на основе Selective Search);
3. Сопоставление каждой гипотезы с местом на карте признаков – т.е. использование единого набора выделенных признаков для каждой гипотезы (координаты гипотез можно однозначно сопоставить с местоположением на карте признаков);
4. Классификация каждой гипотезы и исправление координат ограничивающей рамки (эту часть стало возможным запускать параллельно)

>Fast R-CNN считает CNN-признаки один раз на всё изображение, а не отдельно для каждого proposal.

![](../attachments/Pasted%20image%2020260604141352.png)

[Подробнее](https://habr.com/ru/companies/jetinfosystems/articles/498652/)

#### Faster R-CNN
Fast R-CNN ускорил обработку proposals, но всё ещё использовал внешний алгоритм для их генерации. Faster R-CNN убирает Selective Search, вместо него используется Region Proposal Network

1. Извлечение карты признаков изображения c помощью нейронной сети;
2. Генерация на основе полученной карты признаков гипотез – определение приблизительных координат и наличие объекта любого класса;
3. Сопоставление координат гипотез с помощью RoI с картой признаков, полученной на первом шаге;
4. Классификация гипотез (уже на определение конкретного класса) и дополнительное уточнение координат (на самом деле, может и не применяться).

Основное улучшение произошло именно в месте генерации гипотез – теперь для этого есть отдельная небольшая нейронная сеть, которую назвали **Region Proposal Network**. ## One-stage object detection

One-stage подходы, в отличие от two-stage, не используют отдельный алгоритм для генерации боксов, а просто предсказывают несколько координат боксов для каждого feature map’а, выданного свёрточной нейросетью. Подобным образом действует YOLO, SSD слегка отличается, но идея одна: 1х1 свёртка предсказывает из полученных feature map’ов много чисел по глубине, однако мы заранее договариваемся, какое число что значит.

#### **YOLO** (You Only Look Once)
У автора YOLO очень крутое резюме. В 2016 году придумали, первая однопроходная модель.
![](../attachments/Pasted%20image%2020260604141854.png)
#### SSD (2016)
Входное изображение обрабатывается через предобученную сверточную нейронную сеть (например, VGG16) для извлечения признаков. SSD создает анкерные рамки различных размеров и соотношений сторон по всей сетке, покрывающей изображение. На каждом уровне сети осуществляется предсказание как для классов объектов, так и для координат ограничительных рамок. Это происходит через полносвязные слои, которые используются для предсказания классов и корректировки координат.
![](../attachments/Pasted%20image%2020260604152149.png)
<img src="../attachments/Pasted%20image%2020260604141900.png" width="697">
Главная идея SSD - использовать несколько feature maps разного масштаба.
#### RetinaNet (2017)
Решает проблему несбалансированности классов при использовании одноступенчатых подходов. Основной инновацией RetinaNet является внедрение новой функции потерь, называемой Focal Loss, которая помогает улучшить точность детекции объектов, особенно при наличии большого количества фонов и малочисленных объектов.
![](../attachments/Pasted%20image%2020260604152424.png)

Focal Loss:   
- $FL(p_t) = - α (1 - p_t)^γ log(p_t)$ 
- если пример сложный, модель уделяет ему больше внимания


**Anchors** - это заранее заданные bounding boxes разных размеров и пропорций, расположенные по всему изображению или feature map

**Anchor-free идеи** - подходы, где модель не использует заранее заданные anchors.
Вместо этого она предсказывает объекты напрямую.
