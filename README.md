# Сборник материалов по DL

В основном материалы взяты из Стэнфордского курса, курса Girafe AI, наших прошлых курсов и Яндекс Хендбука, также много просто хороших статей с Хабра и интуиции с ютуба. Большинство источников указаны, и вы можете ознакомиться с оригиналом, а не моей интерпретацией.

Точка входа - "Exam", это темы для экзамена по курсу Центрального Университета, они очень неудобные, если смотреть отдельно от экзамена, просто смотрите темы последовательно. Если хотите подготовиться - можете идти по ссылкам на вопросы
